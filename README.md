# My Favorite Series: Stranger Things

**Stranger Things** is a sci-fi horror drama series set in the 1980s in the fictional town of *Hawkins, Indiana*.

## Why I Love It
- **Great Storyline:** A thrilling mix of mystery, supernatural elements, and 80s nostalgia.
- **Memorable Characters:** Eleven, Mike, Dustin, Lucas, and Hopper have amazing chemistry.
- **Awesome Soundtrack:** Features classic 80s hits like *Running Up That Hill*.

> "Friends don't lie." — Eleven
